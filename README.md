Jcrw Caption translates game subtitles on an Android phone or tablet and displays the translated captions through the separate Android TV / Smart TV receiver overlay.

- 🛠️ **Bug fix** / Various bug fixes & subtitle box sizing adjustments
- 🎮 **Logo Güncellendi** / Logo updated

## Downloads / İndirmeler

Install both applications:

1. **Jcrw Companion (v1.0.44)** on an Android phone or tablet. Connects to PS5 Remote Play, captures subtitle area, and translates text.
2. **Jcrw TV Alıcısı (v1.0.26)** on Android TV / Google TV. Receives captions over local Wi-Fi and displays them above HDMI/game content.
3. **Samsung Tizen & LG webOS**: Built-in web receiver directly accessible via TV Web Browser.

Both devices must be on the same Wi-Fi network.

## Notes

- APK installations outside Google Play may require allowing installs from the file manager/browser used to download them.
- Translation providers and their API keys are chosen by the user.
- This is an independent, community project.
