# Jcrw Caption

Jcrw Caption translates game subtitles on an Android phone or tablet and displays the translated captions through the separate Android TV receiver overlay.

## Downloads

Install both applications:

1. **Jcrw Companion** on an Android phone or tablet. It connects to PS5 Remote Play / Jcrw Chiaki, captures the chosen subtitle area, and translates text.
2. **Jcrw TV Alıcısı** on Android TV. It receives captions over local Wi-Fi and displays them above HDMI/video content.

Both devices must be on the same Wi-Fi network. Start the receiver on the TV, generate a pairing code, then pair it from the Companion app using the TV IP address and the six-digit code.

## Notes

- APK installations outside Google Play may require allowing installs from the file manager/browser used to download them.
- Translation providers and their API keys are chosen by the user. The default option is a free translation provider.
